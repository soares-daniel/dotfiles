# Tmux cheat sheet — prefix is Ctrl+Space

## Sessions
- `s`  fuzzy switch session
- `f`  fuzzy new window in dev session from ~/softdev/code
- `k`  new k8s session (type ssa-dev2, etc.)
- `\`  new empty named session
- `x`  kill current session
- `d`  detach (session keeps running)

## Windows (tabs)
- `c`  new window
- `n` / `p`  next / previous window
- `1-9`  jump to window
- `&`  close window
- `,`  rename window
- `w`  choose window

## Panes
- `v`  split vertical (right)
- `-`  split horizontal (down)
- `←/↓/↑/→`  move between panes
- `z`  zoom pane
- `q`  close pane
- `m`  apply portal-style 3-pane layout

## Copy mode
- `[`  enter copy mode
- `v`  start selection
- `y`  copy and exit

## Other
- `r`  reload tmux config
- `?`  show this cheat sheet
